# Алло, ляля

**Играть:** https://aidomore.github.io/allo-lala/

Игрушечный телефон для малыша: нажимаешь цветные кнопки, звонишь, слышишь гудки,
и зверушка отвечает на билибирдинском языке.

- Без интернета (после первого открытия), без рекламы, без микрофона и камеры.
- Все звуки и голоса синтезируются прямо в браузере, аудиофайлов нет.
- Один и тот же номер всегда попадает к одной и той же зверушке.
- Если долго ничего не нажимать, кто-нибудь позвонит сам.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html`, `style.css` | экраны и оформление |
| `app.js` | логика звонков; настройки в блоке `CONFIG` наверху |
| `audio.js` | гудки, рингтон, голоса |
| `characters.js` | зверушки: цвета, голос, рисунок |
| `sw.js`, `manifest.webmanifest`, `icons/` | установка на экран и офлайн |

## Как выложить на GitHub Pages

1. На github.com создайте репозиторий (например, `allo-lala`), тип **Public**.
2. «Add file → Upload files» и перетащите все файлы и папку `icons`.
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через минуту игра будет на `https://<ваш-логин>.github.io/allo-lala/`.

## Как поставить на планшет

- **iPad / iPhone (Safari):** откройте ссылку → «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** откройте ссылку → меню ⋮ → «Установить приложение».

Откройте игру один раз с интернетом, после этого она работает и в режиме полёта.
Чтобы ребёнок не вышел из игры: на iPad «Гид-доступ», на Android «Закрепление приложения».

Если на iPad нет звука, проверьте громкость и выключите режим «Без звука»
(на свежих версиях iPadOS игра обычно звучит и с ним).
